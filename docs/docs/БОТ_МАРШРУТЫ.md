## Что проверить перед деплоем

```powershell
node --check index.js
node --test routes.test.js
```

Ожидаемо: `node --check` без вывода, тесты 7/7 PASS.

## Деплой (выполняет владелец)

1. Заменить `index.js` и `routes.test.js` в проекте бота (**Yandex Cloud Function**, nodejs22) копиями из `docs/bot/`.
2. Переменная `BOT_ROUTES_JSON` должна **сливаться** с таблицей по умолчанию через `mergeRoutingTable`, а не заменять её: в `index.js` уже есть проверка. Если в окружении задан JSON со старыми ключами `sagitar_tires`/`sagitar_site`, удалить их из JSON — иначе старые маршруты останутся в таблице.
3. Секреты `TG_BOT_TOKEN`, `S3_*` задаются только в окружении функции; в репозитории и в коде их нет.
4. После деплоя проверить глубокую ссылку: `https://t.me/AzAppsFeedbackBot?start=sagitar_shiny_diski_bug` должно сразу предлагать написать обращение, без вопроса «какое приложение».

Деплой агент не выполняет: нет доступа `yc` и секретов владельца. Файлы подготовлены и проверены локально; капчу и 2FA владелец вводит сам.
