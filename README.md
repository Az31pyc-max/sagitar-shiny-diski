# Sagitar · Шины и диски · v2.0_20261127

Подбор шин и дисков по всей России: поле города с поиском, раздельные режимы «Новые / Бу / Все» для покрышек и дисков, мини-переключатель на каждой позиции, 21 российская площадка в «Купить». Для б/у — только Авито и Дром. Наличие и цена уточняются на сайте магазина; подтверждённые цены показываются с датой и источником.

## Проверки

```powershell
python tests/check_structure.py
python tests/check_legal.py
node --test tests/v2.test.js
```

`check_structure.py` запускается из корня проекта «Подбор Резины» и подтверждает, что старые папки `03_Сайт`, `05_Универсальный_подбор`, `02_Иллюстрации` и таблица v3.3 не изменены.

## Ограничения

Партнёрские ссылки и ERID не подключены до регистрации владельца; Авито требует ИП или юрлицо. Сервер обезличенной статистики и админ-вкладка требуют выбора платформы и секретов; в репозитории нет ни пароля, ни хэша. Деплой бота выполняет владелец.
